# MLB Ops Upscale Progress

This folder tracks the step-by-step upscale work for Mallitalytics MLB Ops.

Start with `UPSCALE_ROADMAP.md` before beginning a new session.

Use one file per working session:

```text
SESSION_01_UPSCALE_FOUNDATION.md
SESSION_02_GROWTH_DASHBOARD.md
SESSION_03_CONTENT_SCORING_QUEUE_DECISION.md
```

Each session file should include:

- Goal
- Planned scope
- Completed work
- Files changed
- Tests or checks run
- Open follow-ups

Keep entries short and factual. The goal is to make it easy to resume work without re-reading every diff or chat thread.
